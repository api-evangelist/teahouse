# Teahouse Finance

> Teahouse Finance (founded 2021) is a multi-strategy DeFi asset-management platform that sits as a simplified layer above protocols such as Uniswap V3, running audited smart-contract vaults (LP Vaults, Portfolio Vaults, Easy-Earn delta-neutral, Tea-REX). The public Vault API is a read-only HTTP/JSON interface over permissionless vault catalog, performance, and share-transaction data.

## Endpoints
- GET /vaults — vault catalog with contents
- GET /vaults/type/permissionless — permissionless vaults with latest metrics
- GET /vaults/permissionless/performance/{chainID}/{contractAddress}/{start}/{end} — performance time series
- GET /vaults/permissionless/log/{address}/{startTimestamp}/{endTimestamp} — account share logs
- GET /vaults/permissionless/log/shares/{chainID}/{contractAddress}/{startTimestamp}/{endTimestamp} — vault share logs
